# پروژه تصاویر ابر آروان (Arvan Photos) 🇮🇷

یک اپلیکیشن حرفه‌ای فلاتر برای مدیریت و همگام‌سازی تصاویر با **فضای ابری آروان (S3)**. این پروژه با رعایت استانداردهای مهندسی نرم‌افزار و معماری‌های مدرن پیاده‌سازی شده است.

## [English Version / نسخه انگلیسی](README.md)

## ✨ ویژگی‌های کلیدی

- **اتصال به S3 آروان**: مدیریت کامل فایل‌ها (آپلود، حذف و نمایش) با امنیت بالا.
- **پشتیبان‌گیری هوشمند**: سرویس پس‌زمینه برای آپلود خودکار تصاویر گالری.
- **دسترسی به گالری**: نمایش بهینه تصاویر گوشی با قابلیت انتخاب و برش.
- **معماری Clean**: جداسازی کامل منطق برنامه از رابط کاربری برای توسعه‌پذیری بالا.
- **مدیریت وضعیت با BLoC**: کنترل دقیق جریان داده‌ها و وضعیت‌های مختلف اپلیکیشن.
- **ذخیره‌سازی محلی**: استفاده از دیتابیس SQFlite برای کش کردن اطلاعات و سرعت بالاتر.

## 💎 نکات فنی برجسته

- **پیاده‌سازی سفارشی S3**: استفاده از Dio و امضای نسخه ۴ بدون وابستگی به SDKهای سنگین برای افزایش سرعت و کاهش حجم اپلیکیشن.
- **موتور همگام‌سازی پس‌زمینه**: پیاده‌سازی سرویس پس‌زمینه یکپارچه که تغییرات گالری را پایش کرده و آپلودها را با مدیریت مصرف باتری انجام می‌دهد.
- **کدنویسی تمیز**: رعایت استانداردهای `very_good_analysis` برای تضمین کیفیت و خوانایی کد.
- **مدیریت خطا**: استفاده از الگوهای برنامه‌نویسی تابعی (Functional Programming) برای مدیریت خطاها.

## 🏗 معماری پروژه

این پروژه از اصول **Clean Architecture** پیروی می‌کند:
- **Core**: تنظیمات شبکه، تزریق وابستگی (DI) و موارد مشترک.
- **Domain**: شامل Entityها، Use Caseها و اینترفیس‌های Repository (بدون وابستگی بیرونی).
- **Data**: پیاده‌سازی ریپازیتوری‌ها، مدل‌ها و منابع داده (S3 و دیتابیس داخلی).
- **Presentation**: لایه رابط کاربری و مدیریت وضعیت با BLoC.

## 🛠 تکنولوژی‌های مورد استفاده

- **Flutter/Dart**: فریمورک اصلی.
- **BLoC**: برای مدیریت Stateها.
- **Dio & AWS V4**: برای ارتباط امن با سرورهای S3.
- **GetIt & Injectable**: برای تزریق وابستگی‌ها.
- **SQFlite**: دیتابیس محلی برای کش کردن متادیتا.
- **Background Service**: برای همگام‌سازی در پس‌زمینه.

## 🚀 راه اندازی

۱. دریافت پروژه از مخزن.
۲. تنظیم فایل `.env` در پوشه `assets` شامل کلیدهای دسترسی ابر آروان (S3_ACCESS_KEY، S3_SECRET_KEY و ...).
۳. اجرای دستور `flutter pub get`.
۴. اجرای `dart run build_runner build --delete-conflicting-outputs`.
۵. اجرای اپلیکیشن با دستور `flutter run`.

## 🧪 تست

اجرای تست‌های واحد و بلاک:
```bash
flutter test
```
